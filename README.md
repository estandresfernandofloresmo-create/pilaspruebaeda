Ejecutar la aplicación:
En la terminal (dentro de la carpeta del proyecto), ejecuta:


mvnw spring-boot:run


Consultar el contenido de la pila (GET)
URL: http://localhost:8080/api/v1/pila/mostrar

Método: GET
